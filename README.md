# Listas Conjuntas

<p align="justify">
Uma aplicação web para criação e gerenciamento de listas, desenvolvida como projeto de estudo e prática de desenvolvimento web com JavaScript.
</p>

<p align="justify">
O projeto surgiu da ideia de criar uma ferramenta que permitisse a criação de listas compartilhadas, possibilitando que duas ou mais pessoas adicionassem, removessem e organizassem itens de forma conjunta. A proposta é evoluir a aplicação para oferecer sincronização entre usuários e manter um registro das alterações realizadas em cada lista.
</p>

## ✨ Funcionalidades

* Criar e excluir listas
* Adicionar, editar e remover itens
* Fixar listas
* Alterar o nome das listas
* Modo de organização/edição
* Sistema de temas

## 📚 Objetivo

Este projeto foi desenvolvido para praticar conceitos de desenvolvimento web, principalmente:

* Manipulação do DOM
* Eventos em JavaScript
* Arrays e objetos
* Funções e lógica de programação
* Organização e reutilização de CSS
* Criação de interfaces web
